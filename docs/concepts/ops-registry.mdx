title: Ops registry
description: ASC_OPS, one registry for MCP tools, appstore ops and the hosted API.
---

`ASC_OPS` is the catalog of curated operations. `API_OPS` adds one generated operation per endpoint in Apple's OpenAPI spec (see [Full API coverage](/concepts/full-api-coverage)); `ALL_OPS` is both. Generated and curated ops share the same interface.

| Field | Meaning |
|-------|---------|
| `name` | Stable id, e.g. `appstore_list_builds` |
| `group` | `apps`, `versions`, `testflight`, … |
| `summary` | One line for humans and agents |
| `write` | Whether it changes App Store Connect (or local config) |
| `isWrite` | Optional per-call check; `appstore_request` is only a write when the method is not `GET` |
| `shape` | Zod schema of the arguments |
| `run` | `(client, args) => Promise` |
| `api` | Generated ops only: `{ operationId, method, path, deprecated }` |

## Surfaces

| Surface | How |
|---------|-----|
| MCP (local) | `appstore-mcp` registers every curated op, `appstore_search_capabilities`, `appstore_list_capabilities`, and `appstore_search_operations` / `appstore_describe_operation` / `appstore_call_operation` for all ops |
| MCP (hosted) | Same tools, minus local-file and local-config ops |
| CLI discovery | `appstore ops list [query]`, `appstore ops describe <name>`, `appstore api list`, `appstore api describe <name>`, `appstore search`, `appstore capabilities` |
| CLI invoke | `appstore ops call <name> '<json>'`, `appstore api call <name> --param k=v` |
| REST | `GET https://asc-api.appeeky.com/v1/ops?q=…`, `POST https://asc-api.appeeky.com/v1/ops/<name>` |
| SDK | `listOps`, `getOp`, `invokeOp`, `searchOperations`, `describeOperation` from `@appeeky/app-store-connect-core` |

## Example

```bash
appstore ops list review
appstore ops describe appstore_list_customer_reviews
appstore ops call appstore_list_customer_reviews '{"appId":"1234567890","rating":[1,2],"limit":20}'
```

List operations take `limit` (page size, max 200), `all` (follow `links.next`) and `maxItems` (stop early).

Full lists: [Operations reference](/reference/operations) (curated) and [API operations reference](/reference/api-operations) (generated).
