# Docs

This folder is the [Mintlify](https://www.mintlify.com/) site published at [asc.appeeky.com](https://asc.appeeky.com).

- Config: [`docs.json`](./docs.json)
- Start here: [`introduction.mdx`](./introduction.mdx)
- The operations reference is generated: `pnpm build && pnpm docs:ops`

Preview locally (from this directory):

```bash
npx mintlify dev
```
