## Included

App Store Connect API operations for:

- Apps, app infos and their localizations, categories, age rating, availability, territories
- App Store versions, localizations, builds, App Review details
- Review submissions, release requests, phased release
- Builds, beta details, beta build localizations
- TestFlight groups, testers, invitations, beta app localizations, Beta App Review
- Customer reviews and responses
- Screenshots and app previews, including uploads
- In-app purchases, subscription groups, subscriptions, localizations, price points and price schedules
- Users and invitations
- Bundle IDs, capabilities, devices, certificates, provisioning profiles
- Sales and Trends, finance and analytics reports
- Every other endpoint in Apple's OpenAPI spec as a named, validated [generated operation](/concepts/full-api-coverage) (`appstore api call`, `appstore_call_operation`), or a raw request with `appstore api GET …` / `appstore_request`

## Not included (yet)

| Area | Notes |
|------|-------|
| Uploading binaries (`.ipa`, `.pkg`) | Use Xcode, `xcrun altool` or Transporter; the build upload endpoints exist as generated operations, but the file upload itself is not wrapped |
| Curated commands for Xcode Cloud, Game Center, App Clips, custom product pages, in-app events, offer codes | Every endpoint is available as a [generated operation](/reference/api-operations) |
| Curated price schedule writes | Use the generated price schedule operations (for example `appstore_api_app_price_schedules_create_instance`) |
| Creating certificates (CSR signing) | List and read only |
| Notarization, App Store Server API, StoreKit | Different Apple APIs |
